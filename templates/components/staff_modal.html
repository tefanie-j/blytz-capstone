{% load static %} {% comment %} Staff modal dialog (shared shell). Included once by base_staff.html / base_staff_nosidebar.html. Any link marked with a `data-staff-modal=""` attribute opens that URL in this dialog instead of navigating (see static/js/staff_modal.js). The href stays on the link, so middle-click / open-in-new-tab / no-JS still reach the full page. Optional link attributes: data-modal-title label shown in the dialog header and used for screen readers data-modal-size "narrow" for small forms (default is wide) Used by: Sales pipeline, Accounting, Users. Intentionally NOT used by Orders. {% endcomment %}
